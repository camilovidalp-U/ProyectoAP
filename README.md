## 5. Reporte de visión
**PrestaFácil** es un software de consola desarrollado en Python que permite gestionar préstamos de artículos de manera organizada y eficiente

### Objetivos del software
1. Registrar usuarios con validaciones de datos (nombre, apellido, documento, correo)
2. Registrar ítems categorizados (videojuegos, libros, herramientas, etc.) con ID único
3. Gestionar préstamos asociando usuarios e ítems con tiempo definido (5, 10, 15 o 30 días)
4. Registrar devoluciones generando certificados automáticos en texto plano
5. Facturar ventas cuando un préstamo supera los 30 días, aplicando impuesto del 23%
6. Consultar estadísticas de préstamos activos ordenados por días transcurridos
7. Panel de administrador con reportes de totales y lista de usuarios

### Beneficios
1. Elimina la necesidad de memoria humana
2. Automatiza la generación de certificados y facturas
3. Previene pérdidas económicas al facturar automáticamente después de 30 días
4. Fácil de usar: menú interactivo por consola
5. Datos persistentes mediante archivos planos (no requiere base de datos)
